# Changelog

## [1.0.0] - 2024-04-20
### Initial Release (Fork)
- Forked from `flutter-icapps-license` and rebranded as `jaspr_license_generator`.

- Updated dependencies for compatibility with Dart 3 and the latest Jaspr versions.
- Cleaned up documentation and examples for Jaspr developers.
